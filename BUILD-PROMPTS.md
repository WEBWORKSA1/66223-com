# 66223.com — Research, Concept & Phase-wise Build Prompts

## 1. What "66223" actually means (research summary)

| Lens | Finding | Value to the domain |
|---|---|---|
| **Geography / people** | US ZIP Code 66223 = south **Overland Park, Johnson County, Kansas** (Kansas City metro). ~24,843 residents (Census 2020), ~9,836 households. | **Primary asset.** The only meaning with real search demand. |
| **Economy** | Median household income ≈ $113,707 (ACS 2023); median home value $402,500 (ACS 2023) → $437,500 (2024), up from $263,300 in 2011; ~67% bachelor's+; ~825 businesses / ~11,944 jobs; unemployment ≈ 3.3%. | High-income, high-home-value audience → top-tier ad CPCs (mortgage, insurance, real estate, home services). |
| **Reputation** | Overland Park: Niche #10 Best City to Live (2026); WalletHub #2 Best Place to Raise a Family (2026); Livability #6 (2025). | National relocation search interest, not just locals. |
| **Taxes** | OP city levy ~14.5 mills (lowest in Johnson County); JoCo county levy ~24.1 mills (lowest county rate in Kansas); OP sales tax 9.35%; KS residential assessment 11.5%. | Evergreen "how much will I pay" queries → calculators. |
| **Commerce codes (HS/NAICS/SIC)** | No standard commercial code, product code or industry classification uses "66223". | None — don't build on it. |
| **AI / tech** | No meaningful use of "66223" in AI, models, standards or protocols. | None. |
| **Numerology / memorability** | 66-22-3 is a rhythmic, repeat-pair pattern. In Chinese culture "66" (六六大顺) signals smooth success; repeated digits raise resale appeal to Asian domain buyers. | Resale/brandability upside, not traffic. |

**Verdict:** 66223.com should be a ZIP-anchored **relocation + home-money hub** for south Overland Park. Anything else (AI tool, numerology, generic number site) throws away the one real asset: an exact-match ZIP in a top-ranked, high-income suburb.

## 2. The concept

**66223.com — "Move smarter. Own smarter. Live better in 66223."**
Independent guide for people moving to, buying/selling in, and owning homes in 66223.

**Revenue stack (in order of upside):**
1. **Lead generation** — multi-step "Get matched" funnel → buyer/seller agents (referral fees typically 25–35% of agent commission, or $50–$300/lead), lenders, insurance, movers, roofers ($15–$80/lead).
2. **Google AdSense** — auto ads on high-CPC verticals (mortgage/insurance/real estate/home improvement).
3. **Sponsorships** — Featured Pro $99/mo, Category Sponsor $249/mo, Homepage Partner $499/mo, Contest Title $750/season.
4. **Donations** — tiered support ($5/$25/$100) for operations, prizes, hiring, marketing.
5. **Domain/website acquisition inquiries** — banner on every page → web.works/contact.

**Illustrative month-12 model (assumptions, not promises):** 15k pageviews × $18 RPM ≈ $270 AdSense · 10k visitors × 1.5% form conversion = 150 leads → 15 real-estate @ $100 + 50 home-service @ $25 ≈ $2,750 · 3 sponsors × $199 ≈ $600. **≈ $3.6k/mo.** Leads, not ads, are the business — AdSense is the floor.

**Biggest risk:** leads are worthless without buyers. Line up 3–5 agents/roofers/lenders *before* scaling traffic, and only pass leads with recorded consent (form already includes TCPA-style consent).

## 4. Phase-wise build prompts

Use these in order with any capable AI coding assistant. Each phase ends in a deployable state.

Create a Python generator (`build.py`) that renders every page from a shared layout with: (1) a full-width strip at the very top of every page reading "Contact, if you are interested in this website / domain name / Sponsorship / Advertisement / Partnership" linking to https://web.works/contact; (2) sticky header with Guides, Tools, 66223 Data, Videos, Community, Advertise and a "Get matched free" CTA; (3) footer with independence/trademark notice. Generate ads.txt (`google.com, pub-6620975821265271, DIRECT, f08c47fec0942fa0`), robots.txt, sitemap.xml, sitemap.html, 404.html, .nojekyll. Use relative links so the site works on both github.io and the custom domain. ### Phase 2 — Trust pages (AdSense approval)
